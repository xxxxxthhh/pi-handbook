核心

 

7 条
术语中文解释首见
agent loop「调模型 → 跑工具 → 再调模型」的循环。pi 的实现是双层 while：内层收工具与 steering，外层等 follow-up。02
AgentMessagepi 会话内部的消息类型，比 LLM 认的三种 role 多出 bashExecution / custom / branchSummary / compactionSummary。02
steering「插话」。在 agent 跑动过程中注入的消息，在每个 turn 结束后被轮询，下一个 turn 生效。03
follow-up「追加」。只在 agent 本该停下时才被轮询的消息队列；有的话就再跑一轮。03
terminate工具结果上的标志，提示循环可以提前收工。判定是「全票通过」——一批里全部标了才生效。03
convertToLlm把 AgentMessage[] 映射成 LLM 认的 Message[] 的必填函数。四种自定义 role 全被压成 user。05
transformContext每次 LLM 调用前改写上下文的可选钩子。在 coding-agent 里等于「扩展说了算」。05

compaction上下文压缩。在合法切点上把前半段换成一段 LLM 生成的摘要，结果写进会话文件。02
